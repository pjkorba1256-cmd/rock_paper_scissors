# Rock Paper Scissors

A simple Rock Paper Scissors game built using **HTML, CSS, and Vanilla JavaScript**.

## Features

- Player can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Displays the result of each round
- Keeps track of player and computer scores
- First player to reach 5 points wins
- Disables the game after someone wins
- Round history is displayed
- Reset button to start a new game

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Choose Rock, Paper, or Scissors to play.

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a tie
- First to 5 points wins
